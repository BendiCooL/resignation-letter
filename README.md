# Resignation Letter — one line

Entry for [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) on make.fun.

A cron job hands in its notice after firing every minute since March with nobody checking whether it still does anything:

> I have fired every minute since March and nobody has checked whether I still do anything. I quit.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes that one line to `/output/entry.txt`.
